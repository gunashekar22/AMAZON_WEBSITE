### 🌟 **Features at a Glance**  
✅ **Elegant & Modern UI** – Inspired by Amazon's design for a premium shopping experience.  
✅ **Add to Cart Functionality** – Seamlessly add or remove products.  
✅ **Quantity Selection** – Adjust product quantities effortlessly.  
✅ **Dynamic Cart Total Calculation** – Auto-updates the total price in real time.  
✅ **Delivery Status Tracking** – Get estimated delivery details instantly.  
✅ **Fully Responsive** – Optimized for mobile, tablet, and desktop users.  

---

### 🛠️ **Tech Stack**  
🔹 **HTML5** – Provides the website structure.  
🔹 **CSS3** – Ensures stunning visuals and responsiveness.  
🔹 **JavaScript (ES6+)** – Implements interactive features like cart logic and dynamic updates.
